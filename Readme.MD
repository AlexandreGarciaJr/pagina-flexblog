### Página FlexBlog

- #### Landing page de blog desenvolvida para praticar e consolidar conceitos de CSS Flexbox, como alinhamento, distribuição de espaço e responsividade de layout.

### Tecnologias:

![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white)

### Funcionalidades utilizadas:

- Projeto front-end de uma página de blog criada com foco no aprendizado de CSS Flexbox.
- justify-content
- align-items
- flex-direction
- flex-wrap
